**6. Predictions Analysis**

The prediction analysis shows that the model correctly classified most reviews, while some false positives and false negatives were observed. False positives occurred when non-helpful reviews were predicted as helpful, whereas false negatives occurred when helpful reviews were predicted as non-helpful. The probability scores indicate the model’s confidence in each prediction. 

•	Helpful label: the actual truth 
	 1 = helpful review
	 0= not helpful review

• Prediction: wheat the model predicted.
   1.0 = predicted helpful
	 0.0 = predicted not helpful

•	Probability: the model’s confidence.
	 For example: [0.80, 0.20] means an 80% chance of class 0 and a 20% chance of class 1.

•	Result_type: shows whether the prediction was correct or an error:
•	Correct = prediction matches the actual label.
•	False Positive = the model predicted helpful, but the review was actually not helpful.
•	False Negative = the model predicted not helpful, but the review was actually helpful.
