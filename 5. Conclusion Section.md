**5. Conclusion Section**

The second model used TF-IDF features with PCA for dimensionality reduction, followed by Decision Tree and Random Forest classifiers. PCA reduced the high-dimensional text data while retaining about 43% of the total variance. Both models showed similar performance on training and test sets, with Decision Tree achieving slightly higher accuracy of around 0.75 compared to the Random Forest of around 0.74 of test accuracy, which indicates stable generalization without significant overfitting. 
In general, the PCA-based approach improves computational efficiency by reducing feature dimensionality, but the performance gain is limited due to information loss during compression. To improve the model, the number of PCA components can be tuned, classifier hyperparameters can be optimized, and more advanced models such as gradient boosting can be explored. Moreover, using word embeddings instead of TF-IDF could improve performance by capturing semantic meaning more effectively.
